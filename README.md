# ATLECORE

Recurso digital educativo para fortalecer la coordinación dinámica general en niños de 6 a 7 años mediante actividades físicas, recreativas y progresivas como base para la iniciación al atletismo escolar.

## Descripción

ATLECORE es un recurso digital educativo con implementación práctica diseñado para niños de 6 a 7 años, que busca fortalecer la coordinación dinámica general mediante actividades físicas, recreativas y progresivas. Sus sesiones trabajan habilidades como el equilibrio, el control corporal, los desplazamientos, los saltos, los lanzamientos, la reacción y los cambios de dirección.

## Características

- 14 sesiones organizadas progresivamente
- Actividades adaptadas a niños de 6-7 años
- Enfoque en desarrollo coordinativo
- Base para iniciación al atletismo escolar
- Referenciado con World Athletics Kids

## Estructura del Proyecto

- `index.html` - Página principal
- `style.css` - Estilos y diseño
- `script.js` - Lógica JavaScript y generación dinámica de contenido
- `data/sessions-data.js` - Datos de las 14 sesiones
